To install it on your Android phone:

Step 1 — Host the files on Github (done).

Step 2 — Install on your phone

Open Chrome on your Android phone and go to your GitHub Pages URL
Tap the three-dot menu → “Add to Home screen”
Tap Add — it’ll appear on your home screen with the red heart icon
From then on it opens full-screen like a real app, works offline, and your data stays saved
